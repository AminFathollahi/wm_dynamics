# Matched region-by-modality observability note

The admitted comparison is deliberately bounded to Boran (DANDI 000574), where the existing census supplies co-located single-unit and depth-contact-LFP rows. Rows are joined only on the same patient and session, with the census trial count checked separately for each bin width. The tested quantity is the existing cross-validated nugget-fraction estimator's fittability; no new estimator or cross-corpus pooling is introduced.

The session-level discordance count is diagnostic because sessions repeat within participant. Primary inference averages the LFP-minus-unit fittability indicator within participant and uses a participant-level sign-flip test. Twenty-five of 26 session keys have different trial counts across grains, and channel counts also differ. The result therefore supports only a bounded session-key fittability comparison. It does not identify an anatomical effect: both cells pool their recorded populations, and no region contrast is estimated. Trial admission, population count, measurement physics, and band differences remain confounded; item labels are not used by this label-free estimator. Therefore the artifact does not support claims that LFP recovers a region-specific signal absent from spikes, or any causal or signal-quality modality advantage.
