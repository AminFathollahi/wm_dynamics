# Rank-free component identity

`scripts/run_rank_free_component_identity.py` tests a continuous native-space estimand and does not select an occupied-space rank. Each trial's activity vector is normalized independently before trials are split into two contiguous folds. In each direction of the split, the training trials define both the reference state and the candidate subspace. Evaluation-trial directions are residualized against that training reference, and their leading residual axis is estimated without evaluation labels. The fold score is the squared projection of that axis onto the training-label subspace, bounded between zero and one. Fold scores are weighted by evaluation-trial count.

Categorical candidates use the span of centered training class means. Continuous candidates use the training multivariate-regression coefficient span. Missing-target trials are removed before folds are assigned. A cell is not computed when either fold cannot define a residual axis or candidate basis.

The null permutes complete target rows within each contiguous fold. For every draw and every fold, the candidate subspace is refit from the permuted training labels; the observed label fit is never reused. The reference state and evaluation residual axis are label-free and remain fixed by their trial split. The resulting one-sided Monte Carlo p-value asks whether alignment exceeds the full label-refit null. It assumes target rows are exchangeable within folds; it does not establish a causal or temporally stationary mechanism.

Watters item-count levels are fit separately and combined by valid-trial count using independently seeded null draws. Sessions are then averaged within animal or participant, and independent units receive equal weight. Confidence intervals resample independent units. Pooled null draws use distinct deterministic seeds for every corpus, session, level, and candidate. Benjamini-Hochberg correction covers all computed candidate-by-corpus tests, matching the cross-corpus branch. The artifact reports both session and independent-unit counts and does not turn an entirely uncomputable sweep into a null finding.

Checkpoints are keyed by the exact corpus-session identifier and accepted only when the method version, source hash, data root, fold count, permutation count, schema version, and seed namespace match. Watters checkpoints wrap data loading and are reused for the final summary, so completed sessions are not recomputed.

The method identifies reproducible label-aligned residual geometry conditional on the recorded sessions. It does not identify an attractor, a manifold boundary, or a causal control direction. Pooled inference requires at least four independent animals or participants; corpora below that floor remain explicitly not computable.
